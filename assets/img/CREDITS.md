## pawiwahan/ (template Pawiwahan Prada)

Semua gambar di folder ini adalah ilustrasi buatan pengguna sendiri lewat proyek Google Stitch "Raka & Nadya, Pawiwahan Jawa 3D" (milik pengguna, diunduh 27 November 2026). Bukan domain publik; boleh dipakai karena milik pengguna.

| File | Isi | Olahan |
|---|---|---|
| gunungan.png | Gunungan wayang emas | Apa adanya |
| lembah.jpg | Lembah dan hutan, gaya ukiran sepia | Tepi dipudarkan lewat CSS mask |
| melati.png | Rangkaian melati dan anggrek | Apa adanya |
| kupu.png | Kupu-kupu cokelat | Dibelah kiri-kanan lewat CSS untuk kepak |
| joglo.png | Pendopo joglo, gaya ukiran | Apa adanya |
| pohon.png | Pohon besar dan bambu, gaya ukiran | Apa adanya |
| bingkai.jpg | Latar kayu cokelat dengan sudut emas | Hanya empat sudutnya yang dipakai |
| putra-badan.png, putra-lengan.png, putri-badan.png, putri-lengan.png | Wayang putra dan putri | Bidang cokelat di antara lengan dihapus; lengan belakang dipotong terpisah dengan tepi dipudarkan |

Gambar "pendopo malam" dan foto pasangan dari Stitch tidak dipakai karena tampak seperti foto asli. Foto pasangan di demo memakai `delima/` (dari folder `fotoprewed` pengguna).
